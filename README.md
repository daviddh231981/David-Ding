# Personal Landing Page

This is a simple, responsive personal landing page scaffold. It includes:

- `index.html` — main page
- `assets/style.css` — styles (light/dark theme support via `.light` on `:root`)
- `assets/script.js` — small JS for theme toggle, year, and demo contact handler

How to use

1. Open `index.html` in your browser (double-click or serve with a local server).
2. Replace placeholder text (Firstname Lastname, descriptions, project links) with your content.
3. To enable the light theme by default, add the class `light` to the `html` element in `index.html` or toggle it using the moon/sun button.

Customization ideas

- Swap the SVG avatar for your photo.
- Hook the contact form to a serverless function or form provider (Formspree, Netlify Forms, etc.).
- Add more projects and case studies.
